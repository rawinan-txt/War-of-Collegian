# Pixel Art Characters & Animation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Original 64x64 pixel sprite sheets + a reusable animation/VFX runtime for all 12 heroes, synced to real combat events.

**Architecture:** `tools/` (Node, no deps) generates PNG strips and `assets/characters/animations.{json,js}` from a shared chibi rig + per-character defs. `index.html` loads `animations.js` via `<script>`, loads PNGs with `Image`, and draws frames with a generic `SpriteAnimator`; the old canvas chibi stays as fallback. Combat gets a pending-hit/projectile layer so damage lands on impact. Tests extend `tests/harness.js` (stub `Image`, load `animations.js`).

**Tech Stack:** Node (`zlib`, `node:test`), vanilla JS + Canvas.

**Spec:** `docs/superpowers/specs/2026-11-18-pixel-art-design.md`

## Global Constraints

- Frame 64x64, transparent bg, alpha only 0 or 255, no gradients/anti-aliasing, 1px dark outline, nearest-neighbor draw at 2x, feet baseline fixed (bottom opaque row of idle/walk frames = row 55 ±1).
- Frame counts: idle 4, walk 6, attack 6, skill 10, hurt 3, death 6. Sheets are horizontal strips `idle|walk|attack|skill|hurt|death.png` at `assets/characters/<faculty>/<name>/`.
- Do NOT change hero stats/costs/cooldowns/signature skill effects, faculty/guild/base, Faculty Laser numbers, or DMG/DEF/HEAL attribution.
- Attack interval unchanged; only landing time moves (melee ~0.25s, ranged = fire frame + travel). Report balance-sim before/after.
- Code roster is truth: bug, mecha, lab, night, chem, animal, dental, music, runner, global, public, nurse (+ summoned `dog`).
- Missing/failed sheet must fall back to the old canvas chibi, never throw.

## Review Focus

- Damage applied once per attack (never per animation frame); target dies before projectile lands; attacker dies/stunned mid-swing.
- Projectile/DoT/summon damage still credited to the right hero in CombatStats after the timing change.
- Corpse (death anim) entries never affect combat, stats, targeting or the 35-unit cap; cleared on retry.
- Pause/retry/speed 2x: animation clocks and pending hits must freeze/reset with the battle clock.
- Sheet asset consistency: every config entry points to an existing PNG whose width = frames x 64.
