# Fonts (bundled for offline play)

| Family | Use | Files | License |
|---|---|---|---|
| Mitr (Cadson Demak) | headings, buttons, numbers (cartoon, chunky) | `mitr-{thai,latin}-{500,600}-normal.woff2` | SIL OFL 1.1, see `OFL-Mitr.txt` |
| Kanit (Cadson Demak) | body text, small labels | `kanit-{thai,latin}-{400,500}-normal.woff2` | SIL OFL 1.1, see `OFL-Kanit.txt` |

Source: npm packages `@fontsource/mitr@5.3.0` and `@fontsource/kanit@5.3.0` (woff2 builds of the Google Fonts releases), Thai and Latin subsets only.
The OFL allows bundling and redistribution with the license text; the fonts must not be sold on their own and the Reserved Font Names must not be used for modified versions.
